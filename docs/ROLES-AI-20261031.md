# Cập nhật vai trò và phản hồi AI

- Admin tập trung vào tài khoản, thông báo hệ thống, AI, nhật ký và cài đặt. Dashboard riêng chỉ hiển thị số liệu tài khoản và trạng thái AI. URL học liệu, khóa học, quiz, báo cáo học tập và AI tutor của Admin trả 403.
- Student có Quiz và Bài tự luận liền nhau trong menu.
- Admin đổi nhà cung cấp Gemini/Gateway và ID model Gemini trong Cấu hình AI. Lựa chọn lưu ở system_settings và áp dụng cho yêu cầu mới. Chọn nhà cung cấp chưa có cấu hình sẽ báo chưa kết nối.
- Bổ sung form Lưu API key dành riêng Admin: trường password luôn trống, để trống giữ nguyên key. Key mới lưu tại ai-secrets.local.properties cạnh file SMARTSTU_CONFIG_FILE (máy local: .runtime/ai-secrets.local.properties), ưu tiên hơn key cấu hình ban đầu. Không nằm trong MySQL, Git hoặc WAR. Có hiệu lực cho yêu cầu mới, không cần restart. Sao lưu file này riêng theo cách bảo vệ cấu hình server. Gateway vẫn cần endpoint HTTPS cấu hình ngoài server. Lưu key chỉ kiểm tra định dạng, không tự gọi API để xác minh. Kiểm thử: 6 kiểm tra kho key với dữ liệu giả và 11 kiểm tra HTTP quyền/CSRF/giữ key cũ đều đạt; không thay key thật đang sử dụng.
- Sau khi nộp tự luận thành công, trang kết quả tự gửi POST có CSRF để xin phản hồi AI. Bài nộp đã được lưu trước bước gọi AI, nên lỗi API không làm mất bài. Nút Nhận phản hồi AI cho phép thử lại nếu lỗi. Đã có phản hồi thì dùng kết quả đã lưu.
- Học sinh xem điểm AI đề xuất, từng tiêu chí, dẫn chiếu, lỗi sai và hướng dẫn cải thiện. Đây không phải điểm chính thức. Giáo viên thấy cùng kết quả để chỉnh, lưu nháp hoặc công bố. Lịch sử chấm vẫn giữ nguyên.
- Ảnh nộp được đọc khi chấm theo cùng quyền chủ sở hữu; ảnh quá mờ không được suy đoán chấm tự động.

Kiểm thử: Ant dist thành công; Jasper 0 lỗi; DomainWorkflowTest 55, GeminiAdapterTest 23; tools/test-role-ai-upgrade.ps1 kiểm tra HTTP theo phân quyền mới và gọi Gemini thật với bài mẫu cố ý tính sai. Bộ HTTP cũ có các giả định Admin được giám sát khóa học nên không còn dùng nguyên trạng để xác nhận phạm vi Admin mới.
